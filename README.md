把“搬瓦工”和"Oracle Cloud"放在一起搜的人，心里基本都是同一个问题：甲骨文云有永久免费额度，那我还有必要花钱买搬瓦工吗？反过来问也成立：免费的云服务器，能不能替代一年一百多美元的付费 VPS？

这两个问题其实是一个问题——**你到底为什么需要一台 VPS**。这篇文章会把这个差异拆开讲清楚：Oracle 免费套餐里到底有什么、限制在哪，搬瓦工贵的那部分钱买到了什么，以及哪类人该选哪边。

## 先说结论：这不是“谁更好”，而是“两回事”

先给一个直接的判断，后面再展开依据：

- **Oracle Cloud 的 Always Free 实例**：适合跑博客、机器人、脚本、个人项目这类对网络线路没有要求的负载。它免费、配置不算寒酸，但注册有门槛，且闲置资源可能被回收。
- **搬瓦工的 CN2 GIA 系列套餐**：核心卖点是面向中国大陆优化的线路。如果你开 VPS 的主要目的是让国内访问快、延迟稳，这部分能力 Oracle 免费机给不了，花钱买的就是这个。

所以真正的选择题是：**你要的是“免费的算力”还是“对国内友好的线路”**。这两样东西目前没有一家同时免费提供。

## 两家到底各是什么

Oracle Cloud 是典型的大厂 IaaS 云，和 AWS、Google Cloud 一个性质：按区域部署的数据中心、按量计费、控制台功能非常全，同时用一个“免费套餐”来拉新。搬瓦工则是老牌的 KVM VPS 商家，产品线围绕几条特定线路展开，最出名的是洛杉矶 CN2 GIA 系列以及中国香港、日本东京、大阪、新加坡等地的 CN2 GIA 机房。

## Oracle Cloud 免费套餐：能白嫖到什么，坑在哪

### 免费额度实际包含什么

根据 Oracle 官网当前页面，免费套餐的结构是这样的：注册后先给 **300 美元试用储值，有效期 30 天**，这 30 天内几乎所有 OCI 服务都能随便试。30 天结束后，如果你什么都不做，账户会降级为免费套餐账户，但 **Always Free 服务可以继续用，没有期限**。

对“白嫖一台 VPS”这件事真正重要的是 Always Free 里的计算资源：

- 基于 AMD 的入门 Compute 实例，1 OCPU 配 1GB 内存的规格可以长期免费开着；
- 基于 ARM 的 Ampere A1 实例同样在 Always Free 清单里，可以组合出 2 核 12GB 这类配置，这也是它在中文圈被反复安利的主要原因；
- 每月出向流量有 10TB 左右的免费额度，跑个人服务完全够用；
- 另外还附带对象存储、负载均衡、Autonomous 数据库等一堆免费服务，跑复杂一点的项目也能凑齐组件。

单看纸面参数，这个免费额度和搬瓦工 $169.99/年 的 CN2 GIA-E 套餐（2 核、1GB 内存、20GB SSD、1TB 月流量）比，内存和流量甚至占优。

### 但是有三个绕不开的限制

**第一，注册就有门槛。** 官方 FAQ 写得很清楚：注册需要提供信用卡或借记卡做身份验证，不接受带 PIN 的借记卡和一次性虚拟预付卡；每人只能有一个免费账户，禁止注册多个。没有国际信用卡的话，第一步就可能卡住。

**第二，闲置资源会被回收。** Oracle 官方说明，连续闲置 30 天或更久的免费账户可能被视为废弃账户，可能被暂停或终止；对 Always Free 计算实例，OCI 也会回收长期闲置的资源。也就是说，免费机需要“保持活跃”，不是开一台机器扔在那就不用管了。

**第三，线路没有针对中国大陆优化。** 这一点官方页面不会写，但它是这场对比里最实质的差别：从国内访问 Oracle 的免费实例，走的是普通公网路由，延迟和晚高峰稳定性都看运气。跑个博客、Telegram 机器人没问题，但对延迟敏感的用途就明显不如对国内优化过的线路。

## 几个常见问题

**Oracle 免费机用着用着会被删吗？** 官方政策是闲置 30 天以上的账户可能被暂停或终止，Always Free 计算实例的闲置资源也会被回收。保持一定使用频率、别长期零负载，是大多数用户维持免费机的通行做法。

**搬瓦工和 Oracle 能装一样的系统吗？** 都是基于 KVM 的虚拟化，主流 Linux 发行版都能装，使用层面没有本质区别。差别在使用体验上：搬瓦工的 KiwiVM 面板重装、换机房都是点几下的事，Oracle 的控制台功能全但概念多，第一次上手要花点时间。

**搬瓦工套餐缺货了怎么办？** 热门 CN2 GIA 套餐缺货是常态，官方有库存监控页面可以蹲补货。急用的话可以退而选择有货的相近档位，或者先上 Oracle 免费机顶着。

**年付和季付怎么选？** 搬瓦工年付单价比季付划算，比如 CN2 GIA-E 1GB 年付折合每月约 $14.2，季付是 $49.99。但年付意味着一次性锁一年，如果不确定自己要不要长期用，先季付试水更稳妥。

把两条路摆在一起看，选择其实不难：**Oracle 免费套餐解决的是“零成本有台机器”，搬瓦工解决的是“国内访问质量稳定”**。想明白自己缺哪一样，钱该怎么花就清楚了。
